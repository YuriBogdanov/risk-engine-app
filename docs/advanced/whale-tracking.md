# Отслеживание китов

**Кит** (Whale) в криптовалюте — это кошелёк, держащий достаточно большую долю токена, чтобы влиять на его цену. Когда кит продаёт — цена падает. Когда покупает — растёт.

## Почему концентрация важна?

Если несколько кошельков контролируют большую часть эмиссии, они могут:
- Искусственно **накачивать** цену (pump), чтобы привлечь розничных инвесторов
- Одновременно **сбросить** свои запасы (dump), обрушив цену
- Манипулировать голосованием в DAO-протоколах

## Как интерпретировать данные о держателях

### Нормальное распределение
- Топ-10 кошельков держат **<50%** эмиссии
- Нет явных кластеров (когда несколько адресов явно связаны между собой)
- Среди крупных держателей — известные биржи и DEX-пулы

### Тревожные признаки
- Топ-10 **частных** кошельков держат **>80%** — критический риск
- Несколько новых кошельков одновременно купили большие объёмы — возможная координация
- Адрес создателя входит в топ держателей с долей >10%

## Как отличить «хорошего» кита от «плохого»?

Не все крупные держатели опасны. Нужно различать:

| Тип адреса | Риск | Примеры |
|---|---|---|
| Контракт DEX-пула | Низкий | Uniswap LP, PancakeSwap LP |
| Биржа (CEX) | Низкий | Binance, Kraken hot wallets |
| Контракт стейкинга | Низкий | Официальные farming контракты |
| Частный кошелёк <6 мес | Высокий | Неизвестный адрес |
| Адрес создателя | Очень высокий | Может слить в любой момент |

Именно поэтому Risk Engine **фильтрует** биржевые и DEX-кошельки при анализе китов, считая только **частные** адреса.

## Как выявить связанные кошельки

Мошенники часто распределяют токены между несколькими кошельками, чтобы скрыть реальную концентрацию. Признаки связанности:

- Все кошельки были созданы в один день
- Все получили токены из одного адреса в первый день
- Совершают транзакции одновременно или по очереди
- Похожие паттерны поведения (покупают/продают в одно время)

## Инструменты для отслеживания китов

### Для ручного анализа
- **[bscscan.com](https://bscscan.com)** → Token → Holders — список всех держателей
- **[nansen.ai](https://nansen.ai)** — профессиональный инструмент с маркировкой адресов
- **[arkham.intel](https://arkham.intel)** — граф связей между кошельками

### Для мониторинга
- **Whale Alert** (Telegram бот) — уведомления о крупных транзакциях
- **[debank.com](https://debank.com)** — анализ портфелей крупных кошельков

## Как Risk Engine считает риск китов

Алгоритм Risk Engine:

1. Получает топ-50 держателей от Moralis API
2. **Исключает** из списка:
   - DEX-пулы (из данных GoPlus)
   - Известные биржевые кошельки (из встроенного списка CEX)
   - Нулевой и «мёртвый» адреса (burn addresses)
3. Считает **суммарную долю** оставшихся топ-10 частных кошельков
4. Если их доля **≥80%** — ставит флаг `is_whale_manipulation_risk = true` и добавляет +40 к Risk Score

```
Риск китов ≥ 80% → HIGH: +40 к Risk Score
Риск китов 50–79% → MEDIUM: +20 к Risk Score
Риск китов < 50% → Норма: 0
```
