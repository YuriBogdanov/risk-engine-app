# On-chain анализ

**On-chain анализ** — это изучение данных, записанных непосредственно в блокчейне. В отличие от новостей или заявлений команды, данные блокчейна невозможно подделать или удалить.

## Что можно узнать из блокчейна?

### Смарт-контракт токена
- Исходный код (если верифицирован)
- Наличие опасных функций: mint, pause, blacklist, proxy
- Налоги на покупку и продажу
- Адрес создателя и владельца

### Держатели (Holders)
- Распределение токенов между кошельками
- Доля создателя и владельца
- Наличие крупных «китов»
- Какие адреса — биржи, контракты, частные кошельки

### Транзакции
- История переводов создателя (продавал ли токены?)
- Объём торгов за последние 24 часа
- Подозрительные паттерны (например, массовые продажи сразу после покупок)

### Ликвидность (DEX пулы)
- Реальный объём ликвидности в парах
- Заблокирована ли ликвидность
- Изменение пула ликвидности во времени

## Как читать данные на BscScan / Etherscan

### Находим токен
1. Зайдите на [bscscan.com](https://bscscan.com)
2. Вставьте адрес контракта в поиск
3. Вы попадёте на страницу токена

### Вкладка "Contract"
- **Если контракт верифицирован** — вы увидите исходный код Solidity
- Ищите функции: `mint()`, `pause()`, `blacklist()`, `setFee()`
- Наличие `onlyOwner` перед опасными функциями — владелец имеет особые права

### Вкладка "Holders"
- Первые строки — это обычно DEX-пул и биржи (нормально)
- Смотрите на % у кошельков без маркировки (Private Wallets)
- Суммарная доля топ-10 частных кошельков >80% — высокий риск

### Вкладка "Token Transfers"
- История всех переводов токена
- Найдите адрес создателя и посмотрите его транзакции
- Если создатель регулярно продаёт — плохой знак

## Ключевые метрики для оценки

| Метрика | Безопасно | Подозрительно | Опасно |
|---|---|---|---|
| Налог на продажу | 0–5% | 6–15% | >15% |
| Доля создателя | <5% | 5–15% | >20% |
| Ликвидность пула | >$100K | $10K–$100K | <$10K |
| Топ-10 китов | <50% | 50–80% | >80% |
| Ликвидность заблокирована | Да, >6 мес | Да, <6 мес | Нет |

## Автоматизация: GoPlus Security API

GoPlus — один из лучших инструментов для автоматического анализа безопасности токена. API проверяет более 30 параметров за несколько секунд.

Именно этот API используется в **Risk Engine** при нажатии на анализ токена. Результаты включают:

```json
{
  "is_honeypot": "0",
  "buy_tax": "0",
  "sell_tax": "0",
  "is_mintable": "0",
  "transfer_pausable": "0",
  "is_blacklisted": "0",
  "is_proxy": "0",
  "creator_address": "0x...",
  "creator_percent": "2.5",
  "holder_count": "1523"
}
```
