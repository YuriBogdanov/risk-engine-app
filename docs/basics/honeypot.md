# Honeypot

**Honeypot** («медовая ловушка») — тип мошеннического смарт-контракта, который позволяет **покупать** токен, но **блокирует продажу**. Жертва видит растущую цену, покупает токен, а потом обнаруживает, что продать его невозможно.

## Как это работает технически?

В смарт-контракте прописана специальная проверка в функции `transfer()` или `_beforeTokenTransfer()`. Эта проверка разрешает покупку с DEX, но запрещает продажу для адресов, не входящих в белый список владельца.

Пример упрощённой логики:
```solidity
function _transfer(address from, address to, uint256 amount) internal {
    // Разрешаем покупку (from = пул DEX)
    // Блокируем продажу (to = пул DEX) для обычных кошельков
    if (to == uniswapPair && !_whitelist[from]) {
        revert("Transfer failed");
    }
    // ...
}
```

## Варианты реализации honeypot

### 1. Прямой запрет продажи
Самый простой вид — функция `sell` просто возвращает ошибку для всех кроме владельца.

### 2. Манипуляция со slippage
Контракт выставляет скрытый налог на продажу в 99%, что делает транзакцию невыгодной. Покупка проходит, продажа «зависает» или выполняется с огромными потерями.

### 3. Газовая ловушка
Функция продажи намеренно потребляет огромное количество газа, что делает её выполнение экономически нецелесообразным или технически невозможным.

### 4. Blacklist при продаже
Контракт автоматически добавляет покупателей в чёрный список сразу после покупки, лишая их возможности продать токен.

## Как проверить токен на honeypot?

::: tip Инструменты
- **[honeypot.is](https://honeypot.is)** — самый популярный сервис проверки
- **[tokensniffer.com](https://tokensniffer.com)** — анализ контракта
- **[bscheck.eu](https://www.bscheck.eu)** — для BSC токенов
- **Risk Engine** — встроенная проверка через GoPlus API при выборе токена для свопа
:::

## Признаки honeypot

| Признак | Описание |
|---|---|
| Налог на продажу >50% | Фактически делает продажу невозможной |
| `is_honeypot: true` от GoPlus | Прямое подтверждение |
| Контракт не верифицирован | Код скрыт, невозможно проверить логику |
| Только покупки в истории | Никто ещё не смог продать |
| Transfer Pausable | Владелец может остановить торги в любой момент |

## Что показывает Risk Engine?

При анализе токена мы получаем данные от GoPlus Security:
- `is_honeypot` — прямая пометка как ловушка (→ +100 к Risk Score)
- `buy_tax` / `sell_tax` — налоги на сделки
- `transfer_pausable` — можно ли остановить торги
- `is_blacklisted` — есть ли функция чёрного списка

Если `is_honeypot = 1`, Risk Score автоматически достигает **CRITICAL (100/100)**.
